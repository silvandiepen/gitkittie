# GitKittie Mail

Proposed product, documentation only. Read docs/Features.md, Architecture.md, Classification.md, Decisions.md, Roadmap.md and Plan.md (the work breakdown; each step is a GKM card on the GitKittie board). Follow root AGENTS.md and project-assets/Agents conventions. Native macOS first; shared UI-independent Swift services for later iOS/iPadOS. Apps depend on packages, never each other. Mail providers are authoritative for live mail; Git is optional, never silently uploads mail, and all future Git hosting operations go through GitPont. Security, privacy and correctness outrank convenience. Use synthetic fixtures; never commit real mail or credentials. No shipped feature is implied by this proposal.
