# MAIL-090: Keyboard on the Mac (GKM-061)

**Decision.** Keyboard on the Mac (GKM-061): one Message menu (Send ⇧⌘D, Delete Draft…, Reply ⌘R, Reply All ⇧⌘R, Forward ⇧⌘F, then the conversation actions); File ▸ New Message ⌘N, Attach Files… ⇧⌘A, Import; Edit ▸ Search Mail ⌥⌘F; a Mailbox menu with every sidebar and right-click action (accounts, spaces, Sync Now ⇧⌘N, Notifications…, search filters, the mail folder). Sheets close with Escape; Drafts open with Return. VoiceOver gets the row menu's actions on each list row

**Why.** Two "Message" menus each claimed ⌘⇧U, ⌘⇧L and ⌥⌘↑/↓; account and space actions were reachable only by right-click. Shortcuts follow Apple Mail
