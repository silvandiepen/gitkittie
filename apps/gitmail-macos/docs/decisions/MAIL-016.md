# MAIL-016: Gmail at first release connects over IMAP with an app password, through the IMAP adapter

**Decision.** Gmail at first release connects over IMAP with an app password, through the IMAP adapter; OAuth is added later only as a different sign-in on the same connections

**Why.** No verification or yearly assessment needed; reaches most personal Gmail accounts. Proposed by GKM-008 (ProviderAccess.md), 2026-11-24. **Needs Sil**
