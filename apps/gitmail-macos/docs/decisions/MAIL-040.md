# MAIL-040: Each message has one home

**Decision.** Each message has one home: Quarantine (spam, phishing), Focused (conversations, security mail, unknown or not yet classified mail, transactions to act on or pay, urgent notifications), else Transactions, Updates, Subscriptions or Promotions by purpose. Category views also list their purpose's messages that live in Focused (Transactions shows every receipt and invoice); All Mail shows everything. Transaction urgency: high to act now (payment failed, overdue), normal to pay or attend (invoice, booking), low for records (receipt, order confirmation, payment received). Suspicious mail stays in its view with a warning. The window opens on Focused

**Why.** Lose the noise without hiding anything uncertain (Features.md); a receipt is kept, not acted on. GKM-018
