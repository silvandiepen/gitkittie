# MAIL-021: The app's default mail folder is `Documents/Mail` in its container

**Decision.** The app's default mail folder is `Documents/Mail` in its container; choosing another folder comes with account setup

**Why.** Works in the sandbox with no prompt; a user-chosen folder needs a security-scoped bookmark. GKM-009
